## 1. 系统简介

这是一个桥梁知识检索系统。你提交的资料会被系统自动处理、分类，最终用于支持桥梁知识的问答和检索。

**系统地址：** https://console.bridgingchina.net/

登录后，你会看到左侧菜单，主要用到以下几个页面：

| 菜单项 | 用途 |
|--------|------|
| **入库** | 上传/提交资料的入口 |
| **桥梁** | 管理桥梁档案（名称、类型、位置等） |
| **知识块** | 查看系统切分后的内容片段 |
| **来源** | 查看已入库的资料来源 |

## 2. 你需要准备的材料

### 2.1 桥梁技术文档（核心材料）

每座桥梁需要一份 **Markdown 格式** 的技术文档，内容通常涵盖以下方面：

- **概述** — 桥梁的基本信息（名称、位置、建造年代、类型）
- **结构特点** — 拱券设计、桥墩构造、桥面铺装等
- **历史沿革** — 始建背景、历代修缮记录
- **地理环境** — 桥址的气候、地形、水文特征
- **文化价值** — 文物等级、民俗意义、碑刻记载等

> 不需要每个章节都有，但信息越完整，系统的检索效果越好。

### 2.2 桥梁图片（可选）

- 桥梁现场照片
- 结构示意图
- 地图标注
- 支持 JPG、PNG 格式

### 2.3 桥梁基本信息（用于建档）

| 信息项 | 示例 | 是否必填 |
|--------|------|----------|
| 桥梁名称 | 赵州桥 | **必填** |
| 桥型 | 石拱桥 | 选填 |
| 材料 | 石 | 选填 |
| 年代 | 隋唐 | 选填 |
| 所在区域 | 河北省赵县 | 选填 |
| 功能 | 交通 | 选填 |
| 经纬度 | 37.7654, 114.7762 | 选填 |

## 3. 文档格式要求

系统接受两种文件格式：**PDF**（`.pdf`）和 **Markdown**（`.md`）。

推荐使用 **Markdown** 格式，因为它能被系统更精确地处理。

### 3.1 Markdown 是什么？

Markdown 就是一个普通的文本文件，用一些简单的符号来表示标题、列表等格式。你可以用任何文本编辑器（比如 Windows 的记事本、Mac 的文本编辑）来编写，保存时把文件后缀改为 `.md` 即可。

### 3.2 文档模板

每份文档的**开头**必须包含一个信息头（用三个短横线包裹），然后是正文内容：

```markdown
---
bridge: 桥梁名称
source_type: document
title: 文档标题
---

# 概述

在这里写桥梁的基本介绍，包括名称、位置、建造年代、类型等。

# 结构特点

## 主拱设计

描述拱券的结构、跨度、矢跨比等。

## 桥墩构造

描述桥墩的设计、基础处理等。

## 桥面铺装

描述桥面宽度、铺设材料等。

# 历史沿革

## 始建背景

描述建桥的历史原因和经过。

## 历代修缮

- 某朝某年：修缮内容
- 某朝某年：修缮内容

# 地理环境

描述桥址的气候、地形、水文等自然条件。

# 文化价值

描述文物保护等级、碑刻记载、民俗文化等。
```

### 3.3 信息头字段说明

文档开头被 `---` 包裹的部分叫做"信息头"（front matter）：

```
---
bridge: 赵州桥
source_type: document
title: 赵州桥技术档案
---
```

| 字段 | 含义 | 填写说明 |
|------|------|----------|
| `bridge` | 桥梁名称 | 填写这份资料主要描述的桥梁名称，**必须与系统中的桥梁名称一致** |
| `source_type` | 资料类型 | 填 `document`（正式文档）或 `note`（笔记/备忘） |
| `title` | 文档标题 | 这份文档的标题，用于在系统中显示 |

> 如果一份文档涉及多座桥梁，可以用 `bridges` 代替 `bridge`：
> ```
> ---
> bridges:
>   - 赵州桥
>   - 卢沟桥
> source_type: document
> title: 华北石拱桥对比研究
> ---
> ```

### 3.4 正文格式规则

| 规则 | 说明 |
|------|------|
| 标题用 `#` 号 | 一级标题 `# 概述`，二级标题 `## 主拱设计`，三级标题 `### 细节` |
| 标题层级不超过三层 | 不要用 `####` 及以下的标题 |
| 段落之间空一行 | 每个段落之间要有一个空行分隔 |
| 每段至少 100 字 | 太短的段落会影响系统处理效果 |
| 使用列表和表格 | 列举数据时用 `-` 列表或 `\|` 表格，系统能正确识别 |

### 3.5 PDF 文件的要求

如果你提供 PDF 文件：

- 文件大小不超过 **100MB**
- 建议 PDF 内容按照上面的章节结构组织

## 4. 提交方式一：上传文件（推荐）

这是最简单的提交方式，适用于 `.pdf` 和 `.md` 文件。

### 操作步骤

1. 登录系统，点击左侧菜单的 **「入库」**
2. 点击右上角的 **「+ 新建任务」** 按钮
3. 在弹出的上传区域中：
   - **拖拽文件**到虚线框内，或者
   - **点击虚线框**选择文件
4. 文件开始自动上传，显示进度百分比
5. 上传完成后，任务自动出现在下方的列表中

就这样，系统会自动完成后续的解析、分块、分类、索引等工作。

---

## 5. 提交方式二：直接粘贴文本

如果你手头只有文字内容（比如从网页或 Word 中复制），可以直接粘贴提交。

### 操作步骤

1. 登录系统，点击左侧菜单的 **「入库」**
2. 在页面上找到文本输入区域
3. 将 **Markdown 格式的内容**（含信息头）粘贴到文本框
4. 设置参数：
   - **资料类型**：选择 `document` 或 `note`
   - **桥梁候选**（可选）：填写涉及的桥梁名称，多个用逗号分隔
5. 点击 **「提交入库」** 按钮

---

## 6. 查看处理进度

提交后，你可以在 **「入库」** 页面的任务列表中查看每个任务的状态。

### 状态说明

| 状态 | 含义 | 你需要做什么 |
|------|------|-------------|
| 上传中 | 文件正在上传 | 等待 |
| 排队中 | 等待系统处理 | 等待 |
| 同步中 | 文件同步到服务器 | 等待 |
| 解析中 | 系统正在解析文档 | 等待 |
| **待确认** | 内容已切分完成，等你审核 | **需要你操作**（见下一节） |
| 排队中 (待标识) | 等待语义索引 | 等待 |
| 标识中 | 正在建立索引 | 等待 |
| **已完成** | 资料已入库 | 无需操作 |
| 失败 | 处理出错 | 点击"重运行"重试 |

> 正常情况下，从上传到完成需要 **1-10 分钟**，取决于文档大小。页面会自动刷新状态。

---

## 7. 审核确认入库

当任务状态变为 **「待确认」** 时，表示系统已经把文档切分成知识块，等待你审核。

### 操作步骤

1. 在任务列表中找到状态为「待确认」的任务
2. 你可以选择：
   - **点击「校对」** — 进入编辑页面，查看和修改切分后的内容
   - **点击「确认入库」** — 如果你信任系统的自动处理结果，直接确认

### 校对时主要检查什么？

- 内容是否被正确切分（没有段落被截断或混合）
- 桥梁关联是否正确（内容被归到了正确的桥梁下）
- 分类标签是否合理

> 如果你不确定，直接点「确认入库」也可以，系统的自动处理通常足够准确。后续还可以在「知识块」页面单独编辑。

## 8. 创建新桥梁档案

在提交某座桥梁的资料之前，如果系统中还没有这座桥梁的档案，需要先创建。

### 操作步骤

1. 点击左侧菜单的 **「桥梁」**
2. 点击 **「新建桥梁」** 按钮
3. 填写桥梁信息（至少填写名称）：

| 字段 | 示例 | 说明 |
|------|------|------|
| 名称 | 赵州桥 | **必填**，请使用最常用的名称 |
| 桥型 | 石拱桥 | 下拉选择：石拱桥/木拱桥/铁桥/悬索桥/斜拉桥/梁桥/浮桥/索桥 |
| 材料 | 石 | 下拉选择：石/木/铁/钢/钢筋混凝土/竹/砖 |
| 年代 | 隋唐 | 下拉选择：先秦/秦汉/魏晋南北朝/隋唐/宋元/明清/近现代/当代 |
| 区域 | 河北省赵县 | 填写省市县级别即可 |
| 功能 | 交通 | 下拉选择：交通/军事/景观/水利/铁路/公路/人行 |
| 经纬度 | 37.7654, 114.7762 | 可以从地图应用中查到，选填 |

4. 点击 **「创建桥梁」**

> **重要：** 文档信息头中的 `bridge: 桥梁名称` 必须和这里创建的名称**完全一致**，否则系统无法自动关联。

## 9. 上传桥梁图片

每座桥梁可以上传多张配图。

### 操作步骤

1. 在 **「桥梁」** 列表中，点击进入某座桥梁的详情页
2. 找到 **「桥梁影像」** 区域
3. 点击上传按钮或拖拽图片文件
4. 支持 JPG、PNG 格式
5. 上传后可以：
   - 添加图片说明（caption）
   - 拖拽调整图片顺序
   - 点击删除按钮移除图片

## 10. 注意事项与常见问题

### 命名一致性（最重要）

文档信息头中的桥梁名称 **必须** 与系统中的桥梁档案名称完全一致。

| 情况 | 后果 |
|------|------|
| 文档写 `bridge: 赵州桥`，系统中有"赵州桥" | 自动关联 |
| 文档写 `bridge: 安济桥`，系统中有"赵州桥" | **无法关联**，需要手动处理 |

**建议：** 先在「桥梁」页面确认名称，再写文档信息头。

### 文件格式

| 问题 | 解决办法 |
|------|----------|
| Word 文档（.docx） | 不支持。请另存为 PDF，或将内容复制到 Markdown 文件 |
| 文件超过 100MB | 拆分成多个文件分别上传 |
| 乱码 | 确保文件编码是 UTF-8（用记事本另存为时可以选择编码） |

### 内容质量建议

- **段落不要太短**：每段至少写 100 字以上，太短的段落可能被系统跳过或错误合并
- **用标题分隔章节**：清晰的标题结构能帮助系统准确切分内容
- **避免纯图表**：系统无法识别图片中的文字，重要数据请用文字和表格表述
- **一份文档写一座桥**：尽量每份文档只涉及一座桥梁，便于系统准确归类

### 处理失败怎么办？

1. 在「入库」页面找到失败的任务
2. 点击 **「重运行」** 按钮重试
3. 如果多次失败，检查文档格式是否正确（信息头是否有语法错误等）
4. 如果仍然无法解决，联系技术人员

## 11. 完整示例：从头到尾提交一座桥的资料

以"赵州桥"为例，演示完整流程：

### 第一步：创建桥梁档案

1. 进入「桥梁」→「新建桥梁」
2. 填写：
   - 名称：赵州桥
   - 桥型：石拱桥
   - 材料：石
   - 年代：隋唐
   - 区域：河北省赵县
   - 功能：交通
3. 点击「创建桥梁」

### 第二步：准备文档

用文本编辑器创建文件 `赵州桥.md`，内容如下：

```markdown
---
bridge: 赵州桥
source_type: document
title: 赵州桥技术档案
---

# 概述

赵州桥，又名安济桥，坐落于河北省石家庄市赵县城南的洨河之上，
始建于隋代（公元595-605年），由工匠李春主持建造。
作为世界上现存最早的敞肩式石拱桥，被誉为"天下第一桥"。

# 结构特点

## 主拱设计

赵州桥采用单孔坦拱设计，桥长50.82米，桥宽9.6米。
主拱券净跨37.02米，矢高7.23米，矢跨比约为1:5.1。

## 敞肩设计

桥拱两侧各设两个小拱券，形成"四洞敞肩"的独特形式。
这种设计可减轻桥身自重约15%，同时具有泄洪功能。

# 历史沿革

## 始建

隋朝统一后北方经济恢复，洨河作为重要水运通道，
需要一座兼顾洪涝、通航和陆路交通的桥梁。

## 历代修缮

- 唐代贞元年间：首次大修
- 宋代治平年间：加固拱券
- 明代嘉靖年间：重修桥面
- 1956年：新中国成立后全面修缮

# 地理环境

赵州桥位于洨河之上，华北平原中部。
该区域属温带季风气候，洨河夏季水量较大。

# 文化价值

1961年被列为第一批全国重点文物保护单位。
1991年被美国土木工程师学会认定为"国际土木工程里程碑"。
```

### 第三步：上传文档

1. 进入「入库」→ 点击「+ 新建任务」
2. 拖拽 `赵州桥.md` 到上传区域
3. 等待上传完成

### 第四步：跟踪进度

- 观察任务状态变化：上传中 → 排队中 → 解析中 → 待确认
- 页面自动刷新，不需要手动操作

### 第五步：审核确认

1. 状态变为「待确认」后，点击「校对」查看切分结果
2. 确认内容无误后，点击「确认入库」
3. 系统自动完成索引，状态变为「已完成」

### 第六步：上传图片（可选）

1. 进入「桥梁」→ 找到"赵州桥"→ 点击进入详情
2. 在「桥梁影像」区域上传照片

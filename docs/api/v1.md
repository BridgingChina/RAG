# API V1 参考文档

## 基础信息

- **Base URL:** `/api/v1`
- **Content-Type:** `application/json`

---

## 端点列表

| 端点 | 方法 | 描述 |
|------|------|------|
| `/health` | GET | 健康检查 |
| `/api/v1/ask` | POST | 问答 |
| `/api/v1/ingest` | POST | 入库 |

---

## GET /health

健康检查端点，用于负载均衡探针。

### 响应

```json
{
  "status": "ok"
}
```

## POST /api/v1/ask

根据问题检索相关知识并生成回答。

### 请求体

```json
{
  "question": "赵州桥的结构特点是什么？",
  "target_bridge_id": 1,
  "context": {
    "bridge_id": 1,
    "lvl1": "形制与技术",
    "lvl2": "结构体系",
    "lvl3": "拱桥结构"
  }
}
```

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `question` | string | 是 | 用户问题 |
| `target_bridge_id` | int | 否 | 目标桥梁 ID，用于 Anchor 检索（优先级高于 `context.bridge_id`） |
| `context` | object | 否 | 上下文（用于指定 `bridge_id` 或 taxonomy 过滤维度） |

> 注意：当前版本仅使用 `context.bridge_id` 作为 `target_bridge_id` 的补充；`context.lvl1/lvl2/lvl3` 目前保留，暂不参与检索过滤。

### 响应体

```json
{
  "summary": "赵州桥是一座敞肩式石拱桥...",
  "details": "详细说明...",
  "analogy": null,
  "citations": [
    {
      "chunk_id": 1,
      "source_title": "赵州桥",
      "page_range": null
    }
  ],
  "sources": ["赵州桥"],
  "confidence": {
    "level": "high",
    "reason": "本桥资料有直接相关内容"
  },
  "evidence_groups": {
    "anchor": [
      {
        "chunk_id": 1,
        "bridge_id": 1,
        "bridge_name": "赵州桥",
        "preview": "..."
      }
    ],
    "concept": [],
    "analogy": []
  },
  "degraded": null
}
```

| 字段 | 类型 | 描述 |
|------|------|------|
| `summary` | string | 简要回答（1-3 句） |
| `details` | string | 详细说明 |
| `analogy` | string\|null | 类比案例说明（当类比证据不足时为 `null`） |
| `citations` | array | 引用列表（基于检索证据 chunk 生成） |
| `sources` | array | 来源标题列表（去重后） |
| `confidence` | object | 置信度评估 |
| `evidence_groups` | object | 证据分组（Anchor / Concept / Analogy） |
| `degraded` | array\|null | 降级标志（空表示无降级） |

### 置信度级别

| 级别 | 含义 |
|------|------|
| `high` | 本桥资料有直接相关内容 |
| `medium` | 通用知识有相关内容，但本桥资料不足 |
| `low` | 证据不足或只有间接相关内容 |

### 降级标志

| 标志 | 含义 |
|------|------|
| `facet` | Facet 提取失败 |
| `retrieval` | 检索过程出错 |
| `empty_evidence` | 未找到相关证据 |
| `vector` | 向量检索失败（内部降级） |
| `fts` | 全文检索失败（内部降级） |
| `fetch_chunks` | 拉取 chunk 内容失败（内部降级） |

## POST /api/v1/ingest

导入 Markdown 格式文档到知识库。

### 请求体

```json
{
  "content": "---\nbridges:\n  - 赵州桥\n  - 卢沟桥\ntitle: 古桥对比资料\n---\n\n# 概述\n\n赵州桥与卢沟桥...",
  "source_type": "document",
  "bridge_candidates": ["赵州桥", "卢沟桥"],
  "min_primary_confidence": 0.75,
  "enable_auto_bridge_detection": true
}
```

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `content` | string | 是 | Markdown 文档内容 |
| `source_type` | string | 否 | 来源类型，默认 `document`；若 Front Matter 中存在 `source_type`，以 Front Matter 为准 |
| `bridge_candidates` | string[]\|null | 否 | 额外桥梁候选池（用于消歧） |
| `min_primary_confidence` | float | 否 | 主桥判定阈值，默认 `0.75` |
| `enable_auto_bridge_detection` | bool | 否 | 是否启用自动桥梁识别，默认 `true` |

### Markdown 格式

```markdown
---
bridge: 主桥提示（可选）
bridges:
  - 赵州桥
  - 卢沟桥
source_type: document
title: 文档标题
---

# 章节标题

正文内容...

## 子章节

更多内容...
```

### 响应体

```json
{
  "source_id": 1,
  "title": "古桥对比资料",
  "primary_bridge_names": ["赵州桥"],
  "ambiguous_chunk_count": 1,
  "auto_created_bridges": [],
  "chunk_count": 5,
  "chunks": [
    {
      "content_preview": "赵州桥是一座敞肩式石拱桥...",
      "lvl1": "形制与技术",
      "lvl2": "结构体系",
      "binding_status": "primary",
      "primary_bridge_name": "赵州桥",
      "secondary_bridge_names": ["卢沟桥"]
    }
  ]
}
```

## 错误响应

### 422 Validation Error

请求参数校验失败：

```json
{
  "detail": [
    {
      "loc": ["body", "question"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}
```

### 400 Bad Request

业务逻辑错误：

```json
{
  "detail": "No content found in document"
}
```

### 500 Internal Server Error

服务器内部错误：

```json
{
  "detail": "Internal server error"
}
```
